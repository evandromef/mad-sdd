# Padroes de Desenvolvimento

Este diretorio registra padroes, boas praticas, conceitos e definicoes aprendidos durante a implementacao e revisao das tasks.

Use este diretorio para conhecimento reutilizavel. Observacoes pontuais devem ficar na task ou na sprint correspondente.

## Arquivos

- `backend.md`: padroes de backend, Spring Boot, Java, persistencia e integracoes.
- `frontend.md`: padroes de frontend, Angular, componentes, formularios e experiencia de usuario.
- `testes.md`: padroes de testes unitarios, integracao, contrato e E2E.
- `documentacao.md`: padroes de documentacao, rastreabilidade e atualizacao dos artefatos do plano.

## Quando atualizar

- Apos revisao tecnica complementar de uma task.
- Quando um padrao se repetir em mais de uma implementacao.
- Quando uma boa pratica precisar ser reutilizada em tasks futuras.
- Quando um conceito ou definicao do projeto precisar ficar mais claro para proximos agentes.

## Como registrar

Cada entrada deve ser objetiva e indicar, quando aplicavel:

- task relacionada;
- sprint relacionada;
- ESPEC, RF, RN, RNF ou ADR relacionado;
- contexto em que o padrao foi identificado;
- orientacao pratica para proximas implementacoes.
