## Como adicionar um novo ADR

1. Criar arquivo `adr-XXX-titulo-curto.md` seguindo o número sequencial.
2. Usar a mesma estrutura dos ADRs existentes (Contexto, Decisão, Alternativas Consideradas, Consequências, Referências).
3. Adicionar a linha correspondente nesta tabela.
